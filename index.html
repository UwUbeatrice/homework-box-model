CSS Box Model Guide

Learning about width, spacing and margins

1. Box Sizing

The box-sizing property helps control the total width of an element. With border-box, padding and border are included in the width.

My Example Card

This card has a width of 300px, including padding and border.

CSS used:
width: 300px;
padding: 25px;
border: 5px solid;
box-sizing: border-box;

2. Container

A container keeps the content in the center of the page and prevents it from becoming too wide.

CSS used:
max-width: 1000px;
margin: 0 auto;

3. Margin Collapse

Margin collapse happens when vertical margins of certain elements overlap. Instead of adding together, the larger margin is usually used.

Example of margin collapse

Paragraph with a top margin of 30px.

Ways to prevent margin collapse

Method 1: Add a border to the parent

Here the parent has a small top border.

Method 2: Use display: flow-root

Here the parent uses display: flow-root.

Method 3: Add padding to the parent

Here the parent has top padding.

My conclusion: Margin collapse can sometimes change the spacing between elements. Borders, padding and flow-root can help prevent it.
